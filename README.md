# СберЗдоровье — интерактивный кейс

Чат, виджеты, подробный экран пульса, история проектирования и музыкальный эпилог.

## Локальный запуск

```sh
cd prototype
npm ci
npm run build
npm start
```

Адрес: http://localhost:4317/. Для автоматической пересборки: `npm run watch`.

## Проверка и публикация

`npm run check` запускает строгую проверку TypeScript для презентации, ESLint для исходников приложения и кейса, модульные тесты и сборку. `npm run format` форматирует исходники. `npm run build:pages` собирает статический сайт в `prototype/dist/` с относительными путями и хешами JS/CSS в именах файлов: новые версии не смешиваются со старым кэшем.

Браузерные регрессии проверяют медленную загрузку макета, переходы и периоды пульса, воспроизведение и перемотку музыки. После `npm run build:pages` их можно запустить через `npm run test:browser` (сначала `npx playwright install chromium webkit`). В CI они выполняются в Chromium и мобильном WebKit перед публикацией. Эмуляция WebKit не заменяет проверку Safari на настоящем iPhone.

Публикация запускается вручную через workflow **Publish case to GitHub Pages** после отправки изменений в `main`. GitHub Pages должен использовать источник **GitHub Actions**. Сервер локального журнала событий на опубликованном сайте не используется.
