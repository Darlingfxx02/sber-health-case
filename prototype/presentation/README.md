# Интерактивный кейс СберЗдоровья

Кейс встроен в существующий прототип. Один iframe сохраняет приложение между сценами и самостоятельным исследованием.

## Запуск и проверка

Команды выполняются из `prototype/`:

```sh
npm run build
npm start
npm run check
```

Открыть http://localhost:4317/. `npm run watch` пересобирает и приложение, и презентацию.

## Где редактировать

- `presentation/src/story.ts`: 15 сцен, 3 гипотезы и 18 этапов истории. Поле `events` ссылается на индексы массива в `references/research-log.json`.
- `presentation/src/main.ts`: переходы, история, просмотр изображений и исследование макета.
- `presentation/src/case-touch-scroll.mjs`: мобильный свайп по тексту. Сначала прокручивается длинное описание, затем оставшееся движение передаётся странице; короткий текст сразу листает этапы. После передачи свайп не захватывается текстом следующей сцены.
- `presentation/src/case-layout.mjs`: позиции и масштаб телефона.
- `presentation/src/case-effects.ts`: чёрный контур с белой обводкой и изогнутые указатели из предыдущего кейса.
- `src/hooks/useCaseBridge.js`: восстановление состояний живого приложения и якоря подсветки.
- `src/case-scope.js`: доступные детальные экраны.

Перед историей описание скрывается, телефон перемещается вправо, после завершения перелёта появляются логи. Обратный переход тоже откладывает появление текста. При reduced motion смена мгновенная.

Источники: существующий журнал проекта, локальные снимки `history/`, экспортированные фреймы Figma 21:469, 37:266 и 88:725. Гипотезы сформулированы по словам автора, пользовательские исследования не проводились. История использует Iconsax из проекта. Рамка Dresser взята из предыдущего тестового по прямому запросу автора.

Объём прототипа: чат, виджеты, детали пульса. История чатов, профиль, голос, документы, запись к врачу и другие детали недоступны. Ответы и показатели демонстрационные.

## Эпилог

В конце кейса — широкая чёрная кнопка со звёздами на WebGL. `src/starfield.ts` останавливает отрисовку вне экрана и при скрытой вкладке; без WebGL остаётся статичный фон.

При запуске её звёздный canvas переносится в полноэкранный плеер: блок расширяется из фактических границ кнопки за 700 мс, скругления исчезают. Титры и музыка начинаются после раскрытия. Закрытие сворачивает его обратно за 480 мс; Escape может прервать раскрытие. Reduced motion отключает этот переход. Один canvas и iframe сохраняются.

- `src/agent-text.ts` — текст автора без изменений.
- `src/case-epilogue.ts`, `src/epilogue.css` — полноэкранные титры и ручная прокрутка. Первой строкой перед заголовком идёт «Осторожно, много мата». Из управления видны только громкость и закрытие: чёрный фон, белая обводка 3%, иконки Iconsax. Колесо и свайп перемещают текст; через 2,8 с без ввода автопрокрутка плавно возобновляется. Пробел в области текста ставит паузу; reduced motion начинает с ручной прокрутки. Отдельного режима чтения и кнопок снизу нет.
- `src/crawl-audio.ts` — Web Audio транспорт. При прокрутке назад используется перевёрнутый PCM-буфер с громкостью 0,065 вместо 0,28. Общий слайдер по умолчанию стоит на **5%**, без видимого счётчика. При снятии паузы скорость музыки и текста, а также громкость плавно набираются за 1,4 с. После закрытия звук останавливается. При недоступном файле можно выбрать локальный аудиофайл; он никуда не отправляется.
- Локальный Roboto Condensed 700 с кириллицей: `assets/fonts/roboto-condensed/`, лицензия OFL. Это выбранный аналог, не подтверждённый оригинальный шрифт фильма.

В `assets/audio/main-title.mp3` подключён файл, который автор сам скачал и попросил взять из «Загрузок»: **Main Title and Escape**, по имени файла — версия из *The Last Jedi*, 7:25. Это другая версия относительно исходного скриншота *A New Hope*. Путь задаётся в `src/epilogue-audio-config.ts`. Музыка запускается при открытии титров; медиафайл не загружается до наведения/фокуса на кнопку или открытия эпилога.

Проверки транспорта: `node --experimental-strip-types --test tests/crawl-playback.test.mjs tests/crawl-audio.test.mjs`.

При приближении к кнопке эпилога мокап постепенно исчезает: отступ до его нижней границы 252–72 px. До пересечения с кнопкой он уже полностью скрыт. Обратная прокрутка возвращает его, iframe сохраняется.
